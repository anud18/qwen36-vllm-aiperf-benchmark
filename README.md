# Qwen3.6-35B-A3B-FP8 vLLM benchmark (GB10 / aarch64)

Serve Qwen/Qwen3.6-35B-A3B-FP8 on vLLM in Docker, benchmark with NVIDIA aiperf.

Workloads: chatbot(ShareGPT), coding(codex_swebenchpro), RAG(MultiHopRAG), agent/multi-turn(toolagent, ATBench-Claw).

See **FORMAT.md** (中文版: **FORMAT.zh-TW.md**) for exactly how each dataset is converted and sent to the LLM, and **RESULTS.md** for benchmark numbers.
